# AJ Kurt A. De Los Reyes - Personal Portfolio

Personal portfolio for De Los Reyes AJ Kurt A., an IT student and aspiring web developer from the Philippines.

## Getting Started

1. Install dependencies
```
npm i
```
2. Run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Portfolio content is managed in `public/data.json`. Update that file to change profile details, skills, services, education, experience, or projects.
